和欧混植 — 同じ設定で英数字が混ざったとき

本文 — 行間 1.75 / 字送り 0.02em / palt

このライブラリは日本語のアプリケーションで使うことを前提に組んでいます。和文は字面が大きく 密度が高いため、欧文と同じ行間・字送りでは詰まって見えます。kohaku では本文の行間を 1.75、 字送りを 0.02em に取り、font-feature-settings: "palt" で約物を詰めています。 HTTP や JSON のような英数字が混ざっても破綻しないことを、ここで確認してください。
